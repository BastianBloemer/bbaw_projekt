# Digitalisierte Akademieschriften

Dies ist das Github-Repositorium zu zwei Projekten im Kontext der digitalisierten Akademieschriften (1710-1900) der BBAW. Beide Projekte haben zu ihrem Ziel, die wissenschaftlichen Abhandlungen, die im Laufe der Geschichte der Wissensschaftsakademie von dieser veröffentlicht wurden, in digitaler Form zur Verfügung zu stellen sowie durchsuchbar und erkundbar zu machen.

- Das Projekt innerhalb des Ordners *pipelines/iiif-plattform* 


Die Webanwendung können Sie über [Github-Page](https://bastianbloemer.github.io/bbaw_projekt/pipelines/iiif-plattform/frontend/html/index.html) aufrufen.
